### Week 4 Objectives:

* Explore and practice AWS database, caching, and networking services.
* Practice managing AWS resources using AWS Console, CLI, and Python SDK.
* Understand network components and connection methods between AWS environments.

### Tasks to be carried out this week:
| Day | Task | Start Date | Completion Date | Resource Material |
| --- | --- | --- | --- | --- |
| Mon | - Basic introduction to Amazon DynamoDB: Table, Item, Attribute, Primary Key, and Secondary Index.<br>- Learn about Read Consistency and Read/Write Capacity Mode.<br>- Create a DynamoDB Table and practice adding, reading, and updating data via AWS Console. | 5/10 | 5/10 | <https://000060.awsstudygroup.com/> |
| Tue | - Use AWS CloudShell and Python SDK (Boto3) with DynamoDB.<br>- Practice Create, Read, Update, Delete data operations.<br>- Perform Query, Scan, load sample data, and create Global Secondary Index.<br>- Perform resource cleanup. | 6/10 | 6/10 | <https://000060.awsstudygroup.com/> |
| Wed | - Learn about Amazon ElastiCache for Redis.<br>- Install and configure AWS CLI.<br>- Create Subnet Group and Redis Cluster with Cluster Mode Enabled/Disabled.<br>- Configure access permissions and connect to the cluster.<br>- Practice Set/Get data, Hashes, Publish/Subscribe, and Streams using AWS SDK. | 7/10 | 7/10 | <https://000061.awsstudygroup.com/> |
| Thu | - Explore basic components of AWS Networking: Region, AZ, VPC, Subnet, Route Table, ENI, EIP, Internet Gateway, NAT Gateway, Security Group, and NACL.<br>- Learn about VPC Endpoint and how to connect AWS resources via a private network. | 8/10 | 8/10 | <https://000092.awsstudygroup.com/> |
| Fri | - Practice network connectivity models: VPC Peering, Transit Gateway, and Site-to-Site VPN.<br>- Explore Route 53 DNS, Internal Hosted Zone, and DNS Endpoint.<br>- Practice VPC Endpoint, Endpoint Services, and verify connectivity.<br>- Explore Transit Gateway Network Manager and perform resource cleanup. | 9/10 | 9/10 | <https://000092.awsstudygroup.com/> |

### Week 4 Achievements:

* Understand and practice DynamoDB using Console, CloudShell, and Python SDK.
* Master the deployment and usage of ElastiCache Redis.
* Understand important networking components on AWS.
* Successfully practice VPC Peering, Transit Gateway, VPN, Route 53, and VPC Endpoint.
* Gain foundational knowledge in AWS Database, Caching, and Networking to proceed with advanced practices.
